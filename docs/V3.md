# Portfolio V3

Version 3 makes the existing Django portfolio shorter, more specific, and more useful to Python/Django recruiters. It preserves the current content model, generated CV, case-study routes, accessibility foundation, and contact protections.

## Release scope

- A value-led hero and explicit Bangladesh-to-Germany relocation wording.
- Three evidence-led featured case studies with real project screenshots.
- A shorter homepage without the generic engineering-principles section.
- Concrete, disclosure-safe experience bullets for every public role.
- Project filtering only on the complete project library.
- Non-clickable unavailable states instead of placeholder links.
- A branded social card and complete Open Graph, X, Person, WebSite, and CreativeWork metadata.
- Regression coverage for V3 structure, privacy, metadata, CV generation, contact protection, and project publication controls.

## Evidence policy

All public technical statements must be supported by repository evidence or user-confirmed professional history. Commercial results, production traffic, customer counts, performance improvements, and sole-authorship claims remain excluded unless a source is recorded in `PROJECT_EVIDENCE.md`.

The homepage therefore uses qualitative, verifiable signals—technology specialization, multi-tenant API work, supported domains, validation approach, and relocation intent—instead of invented numerical metrics.

## Content dependencies

The interface supports an admin-managed portrait, but V3 does not publish a substitute or an unverified legacy photograph. A personal portrait can be added only after Rahidul supplies or approves it. Likewise, new quantitative project metrics should be published only through sourced `ProjectMetric` records.

## Verification

Before release:

1. Run `python manage.py check` and `python manage.py test`.
2. Run `python manage.py collectstatic --noinput` in the deployment environment.
3. Review the home, project library, three featured case studies, CV download, contact form, robots, and sitemap routes.
4. Review at 320, 390, 768, and 1440 CSS pixels in both themes, including keyboard navigation, 200% zoom, and reduced motion.
5. Confirm production canonical and social URLs use `https://rahidulislam.dev`.

## Non-goals

- Replacing Django or adding a new CMS.
- Publishing unsupported metrics or confidential workflow details.
- Copying another portfolio's visual identity.
- Adding decorative dependencies or animation without a user-facing purpose.
